# CHARIS AI Prompt Library Documentation

This document outlines the modular prompt templates used by `AIService` and `GeminiProvider`.

## Prompts Overview

### 1. `LUXURY_CONCIERGE_SYSTEM_PROMPT`
Defines the Mayfair Private Concierge persona: empathetic, warm, dignified, and quietly confident. Never sounds like generic ChatGPT or a sales chatbot.

### 2. `EMOTION_DETECTION_PROMPT`
Extracts primary & secondary emotional intent vectors across 14 dimensions (*Gratitude, Love, Respect, Admiration, Celebration, Apology, Sympathy, Friendship, Romance, Achievement, Pride, Family Bond, Nostalgia, Surprise, Excitement*).

### 3. `RECIPIENT_PROFILER_PROMPT`
Synthesizes conversational signals into a 12-dimensional Recipient Persona Profile (*Lifestyle, Hobbies, Luxury Preference, Love Language, Communication Style, Favorite Colors, Travel Preference, Work Style, Personality Traits, Interests, Values, Age Group*).

### 4. `MEMORY_BOX_PROMPT`
Composes the heirloom Memory Box card text:
- Why This Gift Matters
- Emotional Narrative
- Personal Reflection
- Luxury Unboxing Protocol

### 5. `GREETING_MESSAGE_PROMPT`
Drafts calligraphic gift card messages across 6 luxury tones (*Luxury, Romantic, Professional, Family, Friend, Heartfelt*).
